# Práctica 3: árboles generales

- `ejercicio1/GeneralTree.java` contiene la clase base y los métodos incorporados por los ejercicios 3 y 5.
- `ejercicio2`, `ejercicio4`, `ejercicio6` y `ejercicio7` contienen sus implementaciones específicas.
- `ejercicio9/ParcialArboles.java` agrupa resoluciones de ejercicios de parcial.
- El ejercicio 8 (`Navidad`) no tiene implementación en el proyecto original.

Este proyecto depende de `AyED-Practica-1` para reutilizar `ejercicio8.Queue`.
